# Salary_Data.csv

**Status: original capstone input.** This is the exact file used in the Year Up CIS 304 capstone
(the IPython history from Nov 2025 reads `Data-File/Salary_Data.csv`, same 30 rows, same header).

- 30 rows, two columns: `YearsExperience` (1.1 to 10.5) and `Salary` (37,731 to 122,391 USD).
- It is the widely shared public "Salary Data" set from Kaggle used in introductory regression
  tutorials. No real people, no private information.
- Not modified.
